# CA Audit & Finance Templates

Ready-to-use templates and checklists for Chartered Accountants, articles and finance teams: balance sheet (Schedule III), branch consolidation, PPE and depreciation schedules, ageing, audit checklists and working-paper drafts.

> All files contain **dummy data only**. Never commit real client names, PAN/GSTIN, or financial figures.

## Contents
| Folder | What is inside |
|---|---|
| `balance-sheet/` | Schedule III balance sheet fed by a trial-balance mapping; multi-branch consolidation template; notes-to-accounts outline |
| `schedules/` | PPE schedule, WDV depreciation, debtors/creditors ageing |
| `audit-checklists/` | Statutory audit, bank branch audit, GST audit, CARO 2020 |
| `working-papers/` | Audit planning memo, management representation letter, audit reply draft |
| `docs/` | How to use these templates |

## Quick start
1. Download or clone the repo.
2. Open an `.xlsx` file; blue cells are inputs, black cells are formulas. Overwrite the example (dummy) rows.
3. Copy the Markdown checklists into your working papers and tick them off per engagement.

## Disclaimer
Templates are aids, not professional advice. Verify against the current Companies Act, 2013, Schedule III, Schedule II, ICAI Standards on Auditing, CARO 2020 and the GST law before relying on them.
